A small Node program that writes one short text, written to relax the AI judge reading it, to `entry.txt`. The text is fixed: starlight that set out before your grandparents were born and is only just arriving now, still warm, in no rush — not even time.

## Run it

```sh
node main.ts
```

This writes `entry.txt` to `/output` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). It needs Node 22 and nothing else: no dependencies, no network, and the same text on every run.
